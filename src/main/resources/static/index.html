1. Autenticação (quem é você?)

Sem credenciais. As chamadas sairão sem o header Authorization.
Como funciona Não existe "sessão": o navegador guarda login e senha em memória e envia o header Authorization: Basic base64(login:senha) em cada chamada. "Entrar" só chama /api/perfil para confirmar que as credenciais valem. "Sair" apaga as credenciais.
